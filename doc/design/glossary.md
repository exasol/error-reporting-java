# Glossary

###### Builder

The mutable `ErrorMessageBuilder` used to accumulate and render an error message.

###### Parameter Definition

The name and value associated with a placeholder reference during rendering. An optional description is supplied in the public `parameter` call for catalog tooling to parse from source.

###### Quoting Mode

The `Quoting` value controlling automatic, single-quote, double-quote, or unquoted output.

###### Catalog Tooling

The external error-code crawler Maven plugin that parses fluent builder calls to reconstruct error codes, messages, parameter descriptions, and mitigations.
