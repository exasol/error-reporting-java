# Glossary

###### Builder

The mutable `ErrorMessageBuilder` used to accumulate and render an error message.

###### Parameter Definition

The name, value, and optional description associated with a placeholder reference.

###### Quoting Mode

The `Quoting` value controlling automatic, single-quote, double-quote, or unquoted output.

###### Catalog Tooling

The external error-code crawler Maven plugin that parses builder invocations and parameter descriptions.
